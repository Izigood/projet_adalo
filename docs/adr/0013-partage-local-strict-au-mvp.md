# ADR-0013 — Partage des données : local strict au MVP

- **Statut** : Validée (2 octobre 2026) : définitive pour le MVP
- **Date** : 2026-10-02
- **Source** : dossier de création § 3, décision D-03

## Contexte

Options : A, local strict avec échange par export/import de fichier ; B, backend minimal de synchronisation avant le jalon J3. Question tranchée : la première application cible n'exige pas de partage multi-postes.

## Décision

**Option A.** Limite affichée aux concepteurs ; le backend arrive au jalon J4.

## Conséquences

Le partage multi-postes arrive avec le backend et la synchronisation (lots 17 et 18). Aucun backend au MVP.
