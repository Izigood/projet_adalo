# ADR-0015 — Plugins tiers : aucun au MVP

- **Statut** : Acceptée : recommandation du dossier appliquée telle quelle (dossier § 0, tant qu'un ADR ne la modifie pas)
- **Date** : 2026-10-02
- **Source** : dossier de création § 3, décision D-05

## Contexte

Options : A, aucun plugin, composants de première partie uniquement ; B, plugins en iframe isolée.

## Décision

**Option A** (REC-04). Le manifeste de plugin est spécifié mais non chargé.

## Conséquences

Concerne le lot 3. Le catalogue privé et les plugins isolés relèvent du lot 19 (post-MVP).
