# ADR-0018 — Graphe de l'éditeur de workflows : @xyflow/react

- **Statut** : Acceptée : recommandation du dossier appliquée telle quelle (dossier § 0, tant qu'un ADR ne la modifie pas)
- **Date** : 2026-10-02
- **Source** : dossier de création § 3, décision D-08

## Contexte

Options : @xyflow/react ou rendu maison.

## Décision

**@xyflow/react** (MIT), doublé d'une vue liste éditable au clavier pour l'accessibilité.

## Conséquences

Concerne le lot 10. Dépendance liée à React : cohérente avec ADR-0011.
